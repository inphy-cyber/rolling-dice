# Rolling Dice Simulator

A fun Python game where you roll a virtual dice and get a random prize or penalty.

## How to run

1. Open Python on your computer.
2. Run the script named `# Rolling dice simulator.py`.
3. Type `y` to roll again or `n` to exit.

## Features

- Random dice rolls from 1 to 6
- Random rewards and penalties
- Endless gameplay loop
- Simple and beginner-friendly Python code

## Example

```python
Want to test your fate? (y/n): y
Rolling the dice...
You rolled a 4
You win a big prize! 🏆 a vacation for 3 days only!
```

## Notes

This project is a small beginner Python project created for learning random numbers and conditional logic.
